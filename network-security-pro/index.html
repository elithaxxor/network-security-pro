Tool Overview

Nmap (Network Mapper) is a free and open-source network discovery and security auditing tool. It was designed to rapidly scan large networks, although it works fine against single hosts.

Key Features:
  • Host discovery
  • Port scanning
  • Service and version detection
  • OS detection
  • Scriptable interaction with the target

Quick Start Guide

Basic host discovery
nmap -sn 192.168.1.0/24
Ping scan to discover live hosts
Port scan
